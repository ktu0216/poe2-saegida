설치가 막혔을 때

지금 화면에 보이는 것을 고르세요.

  • Edge에서 안 받아져요"일반적으로 다운로드되지 않습니다"
  • 파란 경고 창이 떠요"Windows의 PC 보호"
  • 게임 위에 안 보여요창 모드 전체 화면
  • 받은 파일이 맞는지SHA-256 확인

"일반적으로 다운로드되지 않습니다"가 떠요

새기다는 새로 나온 개인 제작 프로그램이라 Edge가 아직 잘 모르는 파일로 여깁니다.

  1. Edge 오른쪽 위 다운로드 창에서 파일 이름 쪽에 마우스를 올리고 ···(점 세 개)를 누릅니다.
  2. 메뉴에서 유지를 누릅니다.
  3. 확인 창이 뜨면 자세히 표시를 누르고, 새로 나온 그래도 계속을 누릅니다.
  4. 이제 파일 열기를 누르면 설치가 시작됩니다.

Edge 버전에 따라 글자나 위치가 조금 다를 수 있습니다.

"Windows의 PC 보호"가 떠요

코드 서명 인증서가 없는 개인 제작 프로그램이라 Windows가 처음 보는 프로그램으로 경고합니다. 단추가 실행 안 함 하나뿐이어도 닫지 마세요.

Windows의 PC 보호

Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다. 이 앱을 실행하면 PC가 위험에 노출될 수 있습니다.

추가 정보

앱: poe2-saegida-setup-0.2.3.exe
게시자: 알 수 없는 게시자

실행실행 안 함
  1. 글 아래의 추가 정보를 누릅니다.
  2. "게시자: 알 수 없는 게시자"는 개인이 만든 무료 프로그램이라 그렇습니다. 새로 생긴 실행을 누릅니다.
  3. 설치 창에서 다음 → 설치 → 마침. 관리자 권한 없이 내 계정에만 설치됩니다. 바탕 화면 아이콘과 Windows 시작 시 자동 실행은 고를 수 있습니다.

화면은 설명을 위해 간단히 다시 그린 것입니다. 소스 코드는 모두 GitHub에 있습니다.

오버레이가 게임 위에 안 보여요

  • 게임 설정에서 화면 모드를 창 모드 전체 화면(테두리 없는 창)으로 바꿉니다. 전체 화면 모드에서는 오버레이가 게임 위에 보이지 않습니다.
  • Ctrl+Alt+H로 숨겨져 있지 않은지 확인합니다.
  • 패널이 화면 밖으로 나갔다면 패널 우클릭 → 위치 초기화.
  • 로그 파일은 자동으로 찾습니다. 게임을 다른 곳에 설치했다면 우클릭 → 로그 파일 선택…에서 logs\KakaoClient.txt(카카오) 또는 logs\Client.txt(Steam/GGG)를 고릅니다.

받은 파일이 맞는지 확인하기

릴리스 페이지의 파일 옆에 나오는 sha256: 값과, PowerShell에서 아래 명령 결과를 비교합니다.

Get-FileHash .\poe2-saegida-setup-0.2.3.exe

설치 없이 쓰기 · 업데이트 · 지우기

  • 휴대용: poe2-saegida-*-portable.zip을 원하는 곳에 풀고 poe2-saegida.exe를 실행합니다.
  • 업데이트: 새 버전이 나오면 패널 아래에 알림이 뜹니다. 우클릭 → 🆕 업데이트 설치. 설정·진행 기록은 그대로 남습니다.
  • 지우기: Windows 설정 → 앱. 설정·진행 기록(%APPDATA%\poe2-saegida)은 남으니, 완전히 지우려면 그 폴더도 지웁니다.
