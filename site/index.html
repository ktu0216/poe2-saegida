Path of Exile 2 캠페인 길잡이 오버레이입니다. 지역에 들어서는 순간 다음 목적지와 보스, 놓치면 안 될 보상이 게임 화면 구석에 뜹니다. 게임 로그만 읽어서 알아서 따라오니, 가이드를 띄워 둔 브라우저를 오갈 필요가 없습니다.

무료 · Windows 10·11 · 한국어(카카오) / English(Steam·GGG) 클라이언트 · 설치 안내

새기다 — 마음에 새기다, 돌에 새기다. 진행·보상·기록을 놓치지 않게 새겨 두는 도구.

기능

캠페인 내내, 옆에 펼쳐 둔 가이드.

지역을 옮기면 가이드가 따라 넘어가고, 보스를 잡기 전에는 다음 단계로 넘기지 않습니다. 놓치기 쉬운 영구 보상과 퀘스트 패시브도 챙깁니다.

가이드 자동 진행

지역을 옮기면 단계가 따라 넘어갑니다. 마을에 잠깐 들른 건 무시합니다.

보스 전투 표시

보스 대사로 전투 시작·페이즈·처치를 알아채고, 전투 중에는 패널을 한 줄로 줄입니다.

영구 보상 · 퀘스트 패시브

저항·정신력·생명력 보상과 퀘스트 패시브 24점 중 받은 것과 남은 것.

지역 길 찾기 메모 🧭

"벽 따라 시계 방향" 같은 지역마다 짧은 길 찾기 팁.

경험치 효율

지역 레벨과 내 레벨로 경험치 패널티를 계산해 적정 레벨을 보여 줍니다.

액트 스플릿 타이머

액트마다 걸린 시간과 이전 캐릭터 최고 기록(PB)과의 차이.

아이템 비교

게임에서 Ctrl+C 한 장비를 끼고 있는 장비와 비교해 더 좋은지 알려 줍니다.

시세 검색 💰

Ctrl+C 뒤 2초 안에 Ctrl+V. 거래소 최저·중간 가격과 엑잘 환산.

젬 안내

빌드 플래너에 연결된 빌드를 읽어, 지금 레벨에 쓸 젬과 다음에 열릴 젬.

완주 카드 · LiveSplit

액트별 기록이 담긴 공유용 카드(PNG), 스플릿을 LiveSplit 파일로.

엔드게임 기록

세션 지도 수·평균 시간·사망, 최종 보스 도전·처치 기록.

한국어 / English

카카오(한국어)·Steam/GGG(영어) 클라이언트 모두. 화면 언어도 따로 고릅니다.

스피드런

3시간 46분의 경로를, 그대로 따라 달린다.

우클릭 → 가이드 → 스피드런. 메인 퀘스트와 길 위의 영구 보상(패시브 포인트·정신력·저항)만 챙기고, 젬·화폐만 주는 곁가지는 건너뛰는 경로입니다. 레벨 1부터 지도까지 3:46에 끝낸 참고 영상(GuyThatDies, 0.5 기준)의 해설을 단계마다 옮겨 두었습니다.

  1. 액트 135:0035:00
  2. 액트 250:201:25:20
  3. 액트 342:302:07:50
  4. 액트 454:053:01:55
  5. 막간 314:353:16:30
  6. 막간 214:403:31:10
  7. 막간 112:503:44:00

참고 영상의 구간 시간과 누적 시간 (예비 캐릭터 2분 제외). 액트가 끝날 때 가이드에 누적 시간이 함께 나와서, 내 페이스를 바로 비교할 수 있습니다.

요령이 단계 안에

"다리 앞 체크포인트에서 부활하면 아살라가 옆으로 옴", "유물은 하이에나가 떨어뜨림", "지오너는 가운데에 붙잡으면 페이즈 하나 생략" 같은 한 줄 팁.

스플릿 · PB

액트마다 구간 시간을 재고, 이전 캐릭터의 최고 기록(PB)과 차이를 패널에 띄웁니다. 자리 비움과 재시작 공백은 뺍니다.

보스전은 한 줄로

보스 대사로 전투를 알아채고 패널을 한 줄로 줄여 화면을 가리지 않습니다.

LiveSplit · 완주 카드

기록을 .lss로 내보내 다음 캐릭터의 목표로 쓰고, 완주하면 액트별 시간이 담긴 카드(PNG)를 저장합니다.

안전

로그만 읽고, 보여 주기만 합니다.

게임 클라이언트를 건드리지 않습니다. 게임이 스스로 남기는 텍스트 로그를 읽어 화면에 띄울 뿐입니다. 소스 코드는 모두 GitHub에 공개되어 있습니다.

게임 메모리 읽기
게임이 직접 남기는 로그 파일(Client.txt / KakaoClient.txt)만 읽습니다.
게임에 키 입력 보내기 (자동 조작)
화면에 보여 주기만 합니다. 모든 키는 직접 누릅니다.
게임 파일·프로세스 수정
게임 폴더에는 아무것도 쓰지 않습니다.
게임 데이터를 밖으로 보내기
기록은 내 PC(%APPDATA%\poe2-saegida)에만 저장합니다. 인터넷은 새 버전 확인(끌 수 있음)과 직접 누른 시세 검색에만 씁니다. 계정·로그인 정보는 쓰지 않습니다.

클립보드는 게임 창이 앞에 있을 때 복사한 아이템 문구만 읽습니다. Grinding Gear Games, Kakao Games와 관련 없는 개인 제작 도구입니다.

설치

설치는 세 단계.

  1. 설치 파일 받기

    아래 단추로 poe2-saegida-setup-*.exe를 받아 실행합니다. 관리자 권한 없이 내 계정에만 설치됩니다.

  2. 경고가 뜨면 추가 정보 → 실행

    코드 서명이 없는 개인 제작 프로그램이라 "Windows의 PC 보호"가 뜰 수 있습니다. 화면으로 보기

  3. 창 모드 전체 화면으로

    게임 설정을 창 모드 전체 화면(테두리 없는 창)으로 바꾸고, 지역을 옮기면 캐릭터와 진행 위치를 알아서 잡습니다.
