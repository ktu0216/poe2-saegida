# 개발 메모 (동작 방식·데이터 형식)

POE2 새기다. 게임 로그(`KakaoClient.txt` / `Client.txt`)를 읽어서
**지금 접속한 캐릭터**를 알아내고, 그 캐릭터의 진행 위치에 맞는 액트 가이드 단계를 자동으로 보여준다.

## 실행

exe: `build.bat` 을 실행하면 `dist\poe2-saegida\poe2-saegida.exe` 가 만들어진다 (폴더째 옮겨서 사용).

개발용:

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
run.bat
```

## 동작 방식

| 로그 줄 | 용도 |
|---|---|
| `Generating level 15 area "G1_town"` | 지역 코드와 지역 레벨 → 가이드 단계 이동 |
| `이름(직업) 님이 N레벨이 되었습니다.` | 캐릭터 확정, 직업·레벨 |
| `이름 님이 …을(를) 획득했습니다.` | 캐릭터 확정, 영구 보상 기록 |
| `패시브 스킬 포인트 N포인트를 획득했습니다.` | 퀘스트 패시브 포인트 합계 |
| 줄 앞의 `Client <PID>` 가 바뀜 / `Async connecting to …login` | 새 접속 → 캐릭터 다시 확인 |

- 로그에는 로그인한 캐릭터 이름이 직접 남지 않는다. 접속 직후에는 이동한 지역으로 캐릭터를 **추정**하고,
  이름이 들어간 첫 줄(레벨업·보상·사망)이 나오면 **확정**한다. 강둑(`G1_1`)에서 시작하면 새 캐릭터로 본다.
- 새 캐릭터는 강둑 진입 1초 뒤 `Requesting to complete all tutorials due to the client setting` 줄로 즉시 확정한다(튜토리얼 건너뛰기 설정 기준, 없으면 '접속 직후 강둑' 추정으로 대체).
  삭제한 캐릭터와 같은 이름이면 옛 기록은 `이름 (이전 날짜)` 로 보관한다(PB 기록용).
- 확정된 뒤에는 파티원의 레벨업 메시지를 무시한다.
- 리그는 로그에 없어서 게임 설정 파일(`Documents\My Games\Path of Exile 2\poe2_production_Config.ini`)의
  `league_selected` 를 읽는다. 캐릭터별로 기록하고, 다른 리그 캐릭터는 추정 후보에서 뺀다.
- 가이드 위치 규칙
  - 앞쪽 단계에 있는 지역에 들어가면 그 단계로 이동 (건너뛴 단계 허용)
  - 마을은 **바로 다음 단계**일 때만 이동 (정비하러 잠깐 들른 경우 무시)
  - 마을 단계에서 직전 지역으로 돌아가면 한 단계 되돌림 (보스 전 포탈)
  - 그 외에는 뒤로 가지 않음 → 화면에 "가이드 경로 밖" 표시
- 처음 실행하면 로그 전체(150MB 기준 약 2초)를 재생해서 모든 캐릭터의 진행도를 복원하고,
  이후에는 `%APPDATA%\poe2-saegida\progress.json` 에 저장된 위치부터 이어서 읽는다.

## 가이드 데이터

CSV 형식은 `id,area_name,quest` (레임의 PoE Act Guide `act_guide_1.csv` 와 호환 — 메뉴에서 직접 고르면 쓸 수 있다. 자동으로 찾지는 않는다).

1. 메뉴에서 직접 고른 CSV
2. 바탕화면/다운로드/문서 아래 `PoE Act Guide*` 폴더의 `act_guide_1.csv` (자동 탐색)
3. 동봉된 `guides/default_ko.csv` (경로 위주의 간단한 기본 가이드)

`「단어」` 또는 `"단어"` 로 감싸면 강조 표시된다.

## 액트 스플릿 타이머

- 캐릭터별 플레이 시간 = 로그 줄 사이 시간의 합. 자리 비움(`자리 비움 모드를 설정/해제`), 로그아웃·게임 재시작, 30분 넘는 공백은 뺀다.
- 각 액트(`g1_`/`p1_`… 지역 코드 기준)에 처음 들어간 시점이 구간 경계. 지도(`Map…`) 진입 = 캠페인 완료.
- PB = 과거 로그의 **다른 캐릭터** 중 그 액트 최단 기록. 화면: `⏱ 액트 1 5:42 · PB 1:08:50 (-1:03:07) · 전체 5:42`.

## 자동 숨김

1초마다 앞에 떠 있는 창을 확인해서, 게임(`PathOfExile*.exe`)이 아닌 창을 보고 있으면 숨기고 게임으로 돌아오면 다시 보인다.
게임이 꺼져 있으면 보인다. 메뉴의 `게임 창이 아닐 때 자동 숨김` 으로 끌 수 있다.

## 보스·진행 대사

로그에는 NPC·보스 대사가 남는다(내 캐릭터 대사와 오벨리스크 클릭·아이템 습득·거점 활성화는 안 남음). `guides/encounters_ko.json` 에 지역별 보스와 진행 대사를 적어 두었다(과거 로그에서 추출).

- 보스 대사가 나오면 `⚔ 전투 중`, 그 뒤 죽지 않고 지역을 떠나면 `✓ 처치`, 사망하면 `☠`.
- 보스가 있는 단계는 처치 전에 마을에 가도(정비) 다음 단계로 넘기지 않는다.
- 진행 대사 예: 붉은 계곡 `귀신의 목소리` 대사 → `오벨리스크 2/3`, `3/3` (1번째는 대사가 없다).

## 보스전 간단 모드 · Tab 안내

- '곧 보스'(오벨리스크 3/3, 레이티스 `도와주세요` 등 soon 대사) 또는 보스 전투 중이면 패널을 한 줄로 줄이고 알림 창을 숨긴다: `⚔ 녹왕 전투 중 · Lv 5 · 지역 5`.
- 간단 모드가 시작될 때 3초간 `Tab→미니맵` 안내. 키 입력을 대신 보내지는 않는다(자동 입력은 약관 위반 위험).
- 처치/사망/지역 이탈 시 원래대로. 메뉴에서 각각 끌 수 있다.

## 영구 보상 체크리스트

로그의 `…을(를) 획득했습니다.` 줄로 자동 체크한다. 칸 정의는 `guides/rewards_ko.json`.
과거 로그에서 '보상 → 받은 지역'을 뽑아 만들었고, 캠페인을 끝낸 캐릭터 기준 16칸 + 퀘스트 패시브 24포인트.
택1 보상(지구라트 야영지, 버려진 감옥, 죽음의 전당, 키마 등)은 선택지 중 하나를 받으면 완료.
현재 단계 지역에 남은 보상이 있으면 할 일 아래 🎁 로 표시.
퀘스트 패시브(+2)를 주는 12곳(`guides/quest_passives_ko.json` 의 `sources`)도 해당 단계에 🎁 로 표시.

## 지역 길 찾기 메모 (🧭)

현재 지역(하위 지역 포함)에 메모가 있으면 할 일 카드 아래에 작게 표시한다. 메뉴에서 끌 수 있다.
메모는 `guides/zone_tips_ko.json`: [POE2Radar](https://github.com/Sikaka/POE2Radar) 의
`zone_notes.json`(MIT, 원문은 Path of Levelling 2 메모)의 요지를 한국어로 줄여 옮긴 것.
그 프로젝트의 게임 메모리 읽기 기능은 쓰지 않는다(이용약관 위반·계정 위험). 막간은 원문에 지역 메모가 없다.

## 상점 검색 정규식

- 캐릭터에 연결된 빌드 플래너(게임 설정 `active_builds` → `.build` 파일의 `name`)로 `guides/regex_ko.json` 의 규칙 하나를 고른다. 빌드가 없으면 직업으로.
- 마을에 있을 때만 한 줄로 표시, Ctrl+Alt+C 로 복사.
- 마을에서 상인 대사(`렌리: 둘러보게나.` 등, 매번 찍히지는 않음)가 로그에 나오면 자동으로 클립보드에 복사 (20초에 한 번, 메뉴에서 끌 수 있음).

## 아이템 비교 (Ctrl+C)

게임에서 아이템에 마우스를 올리고 Ctrl+C → 클립보드의 아이템 텍스트를 분석해서 장착 아이템과 비교한다.

- 무기: 평균 피해 × 초당 공격 횟수 = DPS, 물리/원소 DPS·공속·치명 차이. 방어구: 방어도·회피·에너지 보호막·생명력·저항 합·이동 속도.
- 장착 기준 등록: 장착 중인 아이템을 **Ctrl+C 를 연달아 두 번 (0.8초 안)** (또는 Ctrl+C 후 Ctrl+Alt+E). 마을 밖에서는 부위별 첫 복사를 자동 등록, 마을에서는 자동 등록하지 않는다(상점 아이템과 구분 불가).
- 반지는 두 칸: 새 반지는 약한 쪽과 비교하고, 등록하면 약한 쪽을 교체.
- 장착 기준이 없으면 직전에 복사한 같은 부위 아이템과 비교.
- 스킬 젬·패시브를 반영한 실제 스킬 DPS 가 아니라 아이템 자체 수치 비교.

## 빌드 젬 안내

게임 빌드 플래너 폴더(`Documents\My Games\Path of Exile 2\BuildPlanner`)의 `.build` 파일을 읽는다. 빌드 사이트(poe.ninja 등)에서 `.build` 로 받아 두면 된다.

- 캐릭터의 빌드 묶음: 메뉴 `빌드 (젬 안내)` 에서 고른 것 > 게임에 연결된 빌드(`active_builds`) > 직업이 맞는 빌드 묶음이 하나뿐이면 그것.
  게임은 패시브 창에서 연결한 빌드를 로그아웃(캐릭터 선택)할 때만 설정 파일에 저장하고 로그에도 남기지 않는다. 그래서 새 캐릭터는 첫 로그아웃 전까지 직업으로 추정한다.
- 같은 묶음의 구간 파일(`Act 1 - …`, `Act 2 - …`, `Interludes - …`, `Budget Endgame - …`, `LvL 1~42 - …`) 중 현재 액트·레벨에 맞는 것을 자동 선택.
- 받은 파일 이름이 잘려 깨졌으면 `<빌드 이름> <번호>. <구간>` 규칙으로 바꿔 두면 된다 (파일 이름과 파일 안 `name` 둘 다, 40바이트 이내).
  예: `젬링 유탄 0. 액트 올인원`, `젬링 유탄 1. Lv 1-42`, `젬링 유탄 2. Lv 43-62`, `젬링 유탄 3. 엔드 초기`, `젬링 유탄 4. 엔드 후기`.
  구간: `Lv a-b`, `액트 N`, `액트 N-M`, `액트 N Lv a-b`·`액트 N Lv a+`(같은 액트를 레벨로 나눈 경우), `막간`, `엔드`, `엔드 초기/중기/후기`, `액트 올인원`(자동 선택에서 제외).
- 젬 이름: 빌드 파일은 게임 내부 ID(`SupportGemMartialTempo`)를 쓰므로 Path of Building(PoE2) `Data/Gems.lua` 로 만든 표(`guides/gem_ids_pob.json`, `tools/update_gem_ids.py`)로 표시 이름(`Rapid Attacks I`)을 찾은 뒤 거래소 이름표로 한국어를 찾는다. 정신력 젬 구분도 이 표의 persistent 태그.
- 패널에 지금 쓸 젬 / 다음 레벨에 쓸 젬, 전체 목록에 보조 젬까지. 레벨업으로 새 젬을 쓸 수 있게 되면 알림.
- 젬 한국어 이름: `guides/gem_ids_pob.json`(내부 ID → 영어) → `gem_names_trade.json`(거래소 영어 → 한국어), 예외는 `gem_names_ko.json`.

## 경험치 효율

위치 줄에 `지역 Lv 40 · 경험치 96%` 처럼 표시한다 (마을 제외). 100% 초록, 80% 이상 노랑, 50% 이상 주황, 그 아래 빨강.
100% 가 아니면 100% 를 받는 지역 레벨 범위도 함께. 계산은 `poe2_overlay/xp.py`:
안전 범위 3 + 레벨/16, 넘은 만큼 d 에 대해 ((레벨+5)/(레벨+5+d^2.5))^1.5 (PoE 공식, PoE2 게임 안에서 확인한 값은 아님).

## 미가공 젬 도우미

미가공 스킬/보조/정신력 젬에 Ctrl+C 하면 캐릭터의 빌드 기준으로 알림 카드를 띄운다.
- 스킬·정신력: 지금 레벨에 쓰는 젬과 다음에 쓸 젬(필요 레벨)
- 보조: 스킬별로 넣을 보조 젬, 미가공 젬 레벨보다 높은 등급(II, III)은 "더 높은 등급 필요"로
정신력 젬 구분은 이름으로 한다(`builds.SPIRIT_HINTS`, 전령·소모 등). 빌드가 연결되지 않았으면 메뉴에서 고르라고 안내.

## 단축키

| 키 | 동작 |
|---|---|
| Ctrl+Alt+→ / ← | 다음 / 이전 단계 (자동 위치가 틀렸을 때 보정) |
| Ctrl+Alt+T | 클릭 통과 켜기/끄기 |
| Ctrl+Alt+H | 숨기기/보이기 |
| Ctrl+Alt+E | 마지막으로 Ctrl+C 한 아이템을 장착 기준으로 |
| Ctrl+Alt+G | 젬 카드: 스킬별 보조 젬, 미가공 보조 젬 Lv1 후보, 다음 레벨 젬 (다른 프로그램이 쓰면 J → F11) |
| Ctrl+Alt+A | 게임 창이 아닐 때 자동 숨김 켜기/끄기 |
| Ctrl+Alt+C | 상점 검색 정규식 복사 (다른 프로그램이 쓰면 Q → F10) |
| Ctrl+Alt+↑ / ↓ | 창 투명도 10%씩 조절 (30%~100%, 메뉴에서도 선택) |
| Ctrl+Alt+R | 영구 보상 전체 목록 (다른 프로그램이 쓰면 Ctrl+Alt+B → J → F9 순으로 대체) |

기본 위치는 게임 창 왼쪽 위, 버프·스킬 아이콘 아래(위에서 8%, 설정 `top_ratio`)이고, 게임을 나중에 켜도 게임 창을 찾으면 그쪽으로 붙는다. 창을 드래그로 옮기면 그 위치를 기억하고, 메뉴의 `위치 초기화` 로 되돌린다.

창은 드래그로 옮기고, 우클릭 또는 트레이 아이콘 메뉴에서 캐릭터 수동 선택·가이드/로그 파일 변경을 할 수 있다.

가이드 우선. ExileCompass와 레임 액트 가이드에서 캠페인 안내에 직접 필요한 것만 가져왔다.

  한국어 가이드 CSV 형식·강조 문법, 캐릭터별 진행 저장(레임), 클릭 통과·전역 단축키(공통)
- 뺌: 타이머/스플릿, 정규식 검색, 제작 가이드, 빌드(PoB) 연동, 음성 명령, 지도 이미지, 테마

- `release\poe2-saegida-<버전>-portable.zip` — 휴대용
